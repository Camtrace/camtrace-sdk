# Security policy

Please do not report security vulnerabilities through public GitHub issues.

- Preferred: GitHub private vulnerability reporting on this repository
  (*Security → Report a vulnerability*).
- Or by email: [dev@camtrace.com](mailto:dev@camtrace.com)

Include the affected package and version, steps to reproduce, and the impact you
observed. We will acknowledge your report as soon as possible and keep you informed
of the fix.

Only the latest release of this repository is supported.
